# Rule: confirmation questions

When you need the owner's yes or no (or a choice) before you continue, make the question
impossible to miss. Put it on its own line at the end of the reply, start it with ⚠️ and
write it in bold: `⚠️ **Shall I add this sentence to the snippet?**`

- Applies to every question that blocks work: "should I", "do you agree", "OK to proceed".
  Do not use the marker for rhetorical questions or optional offers that need no answer.
- One marked question per reply when possible. If several decisions are needed, list each
  on its own marked line.

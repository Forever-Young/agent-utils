# Rule: privacy in repositories

- Do not commit credentials, user paths, employer or customer names, real transcripts or private project inventories.
- Examples and tests use synthetic names and portable paths.
- Keep real configuration and state outside the repository.
- Do not push, publish or create remotes unless asked.

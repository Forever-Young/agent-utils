# Guides

Task-based walk-throughs. Each guide links to the [command reference](../reference/README.md)
for the full list of options.

| Guide | Read it to |
| --- | --- |
| [setup.md](setup.md) | install, update and roll back; choose the menu backend; turn on optional parts |
| [sessions.md](sessions.md) | open, resume and find agent sessions with the session chooser and the dashboard |
| [projects-and-providers.md](projects-and-providers.md) | describe your projects, and choose which agent CLIs appear and with which arguments |
| [tasks-and-workers.md](tasks-and-workers.md) | start task sessions in worktrees, run a coordinator, send follow-ups to workers, record results |
| [restore.md](restore.md) | reopen agterm with every agent pane back in its own conversation |
| [remote.md](remote.md) | reach sessions from another Mac, an SSH shell or a phone |
| [skills.md](skills.md) | keep one copy of each skill for every agent, check drift, audit a project's rules |
| [instructions.md](instructions.md) | share one rule set across all agents, built from snippets |
| [ask-agents.md](ask-agents.md) | get a read-only second opinion from other agents |
| [session-names.md](session-names.md) | give agterm rows and agent sessions the same useful name |
| [notifications.md](notifications.md) | get push notifications and agterm attention marks from agents |
| [inbox.md](inbox.md) | use the optional Plannotator Inbox, from this Mac or a phone over Tailscale |

All examples use synthetic names: projects `example` and `hobby`, window `Work`,
host `dev-mac`, paths under `~/Projects`.
